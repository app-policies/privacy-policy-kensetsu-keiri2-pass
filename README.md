# 建設業経理士Pass プライバシーポリシー

最終更新日: 2026年10月21日

提供者: Passmate（パスメイト）

本ポリシーは「建設業経理士Pass」のiOS版およびAndroid版における情報の取り扱いを説明します。本アプリは建設業経理士検定試験2級の学習を補助する非公式アプリであり、試験実施団体や行政機関による提供・監修・承認・提携を示すものではありません。

## 1. 利用する情報と目的

- **端末内の学習データ**: 回答履歴、正誤、苦手問題、連続学習日数、学習設定などを、学習記録と復習のため端末内に保存します。本アプリ独自の学習データのクラウド同期機能はありません。
- **利用状況の分析データ**: Firebase Analyticsを通じ、アプリの起動、画面や機能の利用、出題分野・モード、正誤、回答数、得点、購入操作、Premium状態などのイベントと、アプリ・OSのバージョン、端末やアプリインスタンスの識別情報などを処理します。利用状況の把握と機能・品質の改善に使用します。氏名を登録しない場合でも、識別子により同一の端末やアプリの利用を関連付けることがあります。
- **広告関連データ**: Google Mobile Ads / AdMobが、広告表示、効果測定、診断、不正防止のため、IPアドレス、IPアドレスから推定されるおおよその地域、広告識別子等の識別情報、広告やアプリの操作情報、端末・SDKの診断情報を収集・処理し、広告関連事業者と共有する場合があります。本アプリはGPSによる正確な位置情報を要求しません。
- **購入関連データ**: iOSではApp Store、AndroidではGoogle Playと、両OS共通のRevenueCatを利用します。商品ID、購入履歴、取引・購入の検証情報、購入権利の状態、RevenueCatが発行するアプリ利用者用の識別子などを、買い切りPremiumの有効化、購入の検証・復元、不正防止、売上・購入状況の確認のために処理します。カード番号等の決済情報は各ストアが取り扱い、本アプリは取得しません。
- **お問い合わせ**: 利用者がメールを送信した場合、メールアドレス、問い合わせ内容、添付資料、アプリ名・バージョン等を受け取り、回答と不具合調査のために使用します。メール送信前に内容を確認・編集できます。

本アプリの学習用分析イベントには、問題・選択肢・解説の本文、入力した仕訳や金額そのもの、問題IDそのもの、氏名や勤務先などの実務情報を含めません。この説明は、SDKが自動処理する識別情報や、利用者自身が問い合わせメールに記載する情報まで送信されないことを意味するものではありません。

Android版4.0.1（ビルド9）以降では、Firebase Analyticsによる利用分析は初期状態で無効です。「設定」の「利用状況の分析を許可」をオンにした場合に有効となり、同じ設定から停止できます。オフでも学習機能と購入・復元を利用できます。停止は、それまでに外部サービスへ送信したデータの削除を意味しません。iOS版および以前のAndroid版には、この設定がない場合があります。

## 2. 広告とアプリ内課金

無料利用時には広告を表示します。広告リクエストは非パーソナライズ広告を指定していますが、非パーソナライズ広告でも広告の配信・計測・不正防止に必要な情報の処理は行われます。非パーソナライズ指定だけで、識別情報の処理や、地域ごとに必要な同意がすべて不要になるわけではありません。

Android版4.0.1（ビルド9）以降では、Googleの同意管理機能で広告配信の可否を確認し、必要なメッセージの表示後に広告を読み込みます。確認できない場合は広告を読み込みません。同意の管理画面が必要な場合、「設定」に「広告のプライバシー設定」を表示し、選択を変更できるようにします。

Premiumは買い切りのアプリ内課金です。購入権利が確認できる場合、対象の学習機能を利用でき、アプリ内広告が非表示になります。広告非表示になっても、購入権利の確認・復元や利用状況の分析が一律に停止するわけではありません。

## 3. 外部サービスと情報の送信

分析・広告・購入管理のため、必要な情報が次のサービス提供者に送信されます。各提供者による取り扱い、保持期間、処理地域等は各社のポリシーやサービス設定によります。情報が利用者の居住国以外のサーバーで処理される場合があります。

- [Firebase / Google Analyticsのプライバシー情報](https://firebase.google.com/support/privacy)
- [Googleのプライバシーポリシー](https://policies.google.com/privacy)（AdMob / Google Play等）
- [RevenueCatのプライバシーポリシー](https://www.revenuecat.com/privacy)
- [Appleのプライバシーポリシー](https://www.apple.com/legal/privacy/)

SDKとの通信には各サービスが提供する暗号化通信を使用します。外部サイトや広告のリンクを開いた後の取り扱いは、遷移先のサービスのポリシーが適用されます。

## 4. 保存期間と削除

端末内の学習記録は、学習データのリセットまたはアプリの削除まで保存されます。アプリ内の「学習データをリセット」では回答履歴・苦手問題等を初期化しますが、文字サイズ等の設定やストアの購入履歴は削除しません。端末・OSのバックアップ設定によっては、再インストールや機種変更時にデータが復元される場合があります。

分析・広告・購入関連データは、それぞれの利用目的、サービス設定、購入の復元、不正防止、法令上の義務に必要な期間保持されます。端末内のリセットやアンインストールだけで、外部サービスに送信済みのデータやストアの取引記録がすべて削除されるわけではありません。

お問い合わせの情報は、対応・調査に必要な期間保持し、その後は法令上の保存義務や紛争対応等の必要性を踏まえて削除または個人との関連を除去します。情報の確認・訂正・削除等のご希望は、下記窓口にご連絡ください。対象の特定に必要な範囲で確認を行い、利用可能な手段と適用法令に従って対応します。匿名の識別子しかない場合等は、対象を特定できないことがあります。パスワードやカード番号は送らないでください。

## 5. 利用者による管理

本アプリに独自のアカウント作成・ログイン機能はありません。購入の復元には購入時のストアアカウントを使用します。広告識別子・広告プライバシー・バックアップの設定は、OSやGoogle・Appleの設定から管理できます。Premiumの購入は広告を非表示にするもので、外部サービスのデータ削除を行う機能ではありません。

本アプリは13歳未満の児童を主な対象としていません。児童の情報が不適切に提供されたと思われる場合は、下記窓口にご連絡ください。
